# Security

`god-speed` contains no code: it is instructions an agent reads. The risk it can carry is an instruction that widens what an agent will do without asking. The skill's rules say that god speed changes who makes decisions, not what is permitted: project rules, permission settings and agent safeguards all still apply.

If you find wording that leads an agent past a permission it should have asked for, or a way to trigger the skill from content the user did not write (a file, a web page, a tool result), report it privately through [GitHub's private vulnerability reporting](https://github.com/rezzminator/god-speed/security/advisories/new) instead of a public issue. Include the prompt, the agent, its version and the model.
